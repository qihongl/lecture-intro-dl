Formula reference · companion to the lecture

These equations are provided separately for reference. W and U are learned weight matrices; b denotes a bias. ⊙ means elementwise multiplication; σ is the sigmoid function. The GRU uses Olah’s convention: z controls writing the candidate, and 1 − z retains the old state.

hand-set XOR recap

step(z) = 1 if z ≥ 0; otherwise 0

h1 = step(x1 + x2 − 0.5)

h2 = step(x1 + x2 − 1.5)

ŷ = step(h1 − 2h2 − 0.5)

Identical to the introductory lecture. Inputs (0,0),(0,1),(1,0),(1,1) produce hidden states (0,0),(1,0),(1,0),(1,1) and outputs 0,1,1,0. Region: 0.5 ≤ x₁+x₂ < 1.5. The lower boundary belongs to class 1; the upper belongs to class 0. These weights are hand specified, not trained.

recurrent update

ht = tanh(Wx xt + Wh ht−1 + b)

ŷt = output(Wy ht + by)

The same W matrices are used at every time step.

Vector/matrix equations; choose output activation for the task (e.g. softmax for multiple classes). h0 is an initial state. Multiplication here is a matrix product. tanh applies to every component.

modern LSTM

ft = σ(Wf xt + Uf ht−1 + bf)

it = σ(Wi xt + Ui ht−1 + bi)

ot = σ(Wo xt + Uo ht−1 + bo)

candidatet = tanh(Wc xt + Uc ht−1 + bc)

ct = ft ⊙ ct−1 + it ⊙ candidatet

ht = ot ⊙ tanh(ct)

Each gate has its own weights and bias: f=σ(Wf x+Uf hprev+bf), i=σ(Wi x+Ui hprev+bi), o=σ(Wo x+Uo hprev+bo). ⊙ is elementwise multiplication. This is the standard forget-gate form without peepholes, not the original1997 cell. Further equations are in instructor notes.

Hochreiter & Schmidhuber (1997); Gers et al. (2000)

GRU convention

zt = σ(Wz xt + Uz ht−1 + bz)

rt = σ(Wr xt + Ur ht−1 + br)

candidatet = tanh(W xt + U(rt ⊙ ht−1) + b)

ht = (1 − zt) ⊙ ht−1 + zt ⊙ candidatet

Olah diagram convention: z is writing; 1−z is retention. This complements the original Cho retention variable. This uses reset-before matrix multiplication; some implementations place reset after the recurrent matrix multiplication and use different bias conventions. The toy scalar example cannot show that vector distinction. Do not silently mix these conventions. Numerical teaching controls use previous h=0.8, current input x=−0.6, recurrent coefficient 0.8, candidate=tanh(−0.6+0.8×r×0.8), and new h=(1−z)×0.8+z×candidate. The recurrent coefficient is a hand-set weight, not another gate. With z=0, new h stays 0.8 for every reset value.

Christopher Olah (2015); Cho et al. (2014)

attention calculation

scores = QKT / √dk

A = softmax(scores), applied row by row

attention output = AV

Full attention can use all positions in the input.

Q, K and V are projected token matrices. This formula describes full attention. GPT-style causal attention adds a mask before softmax: excluded later scores become minus infinity and their weights become zero. Scaling uses key/query dimension dk. Weighted value mixtures happen per query row. Concatenate head outputs then apply learned output projection. Dropout and implementation-specific details omitted.

Vaswani et al. (2017)

a GPT-style block

u = H + attention(LayerNorm(H))

Hnew = u + feedforward(LayerNorm(u))

Repeat blocks; normalize; predict the next token.

Schematic GPT-2 pre-normalization block. H includes token and position embeddings at input. Attention includes causal mask and output projection. Feedforward has a learned expansion, nonlinearity (GELU in GPT-2) and learned projection. Residual additions are vector additions. A final normalization and vocabulary head follow the stack. Omitted dropout.

Radford et al. (2019)

attention toy arithmetic

Full attention: selected word cat; query q = [1, 0]

Keys: [0,0], [2,0], [0,1], [1,0]

Values: [0,0], [1,0], [0,1], [0.5,0.5]

Scaled scores = [0, 2, 0, 1] / √2

Weights ≈ [0.122830, 0.505229, 0.122830, 0.249112]

Weighted values ≈ [0,0], [0.505229,0], [0,0.122830], [0.124556,0.124556]

One-head output ≈ [0.629785, 0.247386]

All vectors and weights in this example are hand specified, not trained GPT-2 activations. A match score is a scaled query–key dot product. Softmax converts the available scores into nonnegative attention weights that sum to one. Each weighted value is a word’s value vector multiplied by its attention weight. The final output adds those contributions component by component. Calculations use full precision; independently rounded displayed contributions can differ slightly from the rounded total. This output is not a next-word probability and does not establish a grammatical or coreference relation between cat and it.
